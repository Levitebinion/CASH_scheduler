# CASH_scheduler
## dynamic scheduler 
### Team 9:

 

Team Name: Dynamo Timekeepers

 

Members: Kevin Tran, Henry Fletcher, Alan Binion, Isaiah Buluran

 

Project Idea: A scheduler that tells you how much time you have left for events you set. It also is capable of predicting any regular events that you have and asks to automatically set it into the schedule. As you get closer to the event, alarms are raised on how much time you have left to attend the event. 

 

Language: C++

 

 

IDE: VS Code
